# Proyek 84: Text Cleaner (Pembersih Spasi Ganda & Teks Kotor)

Proyek ini adalah aplikasi web praktis untuk membersihkan teks dari karakter spasi berlebih, spasi ganda, karakter *tab*, dan baris kosong berulang. Sangat berguna untuk merapikan teks hasil *copy-paste* dari PDF, file dokumen, atau artikel web. Dibuat menggunakan **HTML5, CSS3, dan Vanilla JavaScript (RegEx)**, cocok sebagai materi pembelajaran ekspresi reguler (*Regular Expressions*) dasar bagi siswa SMK/pemula.
